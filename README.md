## 📚 Learning Modules

| Module | What Kids Learn | Age Group |
|:---|:---|:---|
| 🔤 **A-Z Alphabet & Phonics** | 26 letters, sounds, example words with speech | 2-6 years |
| 🔢 **Numbers 1-20** | Counting, number words, visual dots | 2-7 years |
| 🦁 **Animal World** | 12 animals, names, sounds | 2-6 years |
| 🎨 **Colors & Shapes** | 12 colors, shape recognition | 2-5 years |
| 🎵 **Nursery Rhymes** | 6 classic rhymes with read-aloud | 2-8 years |
| ✏️ **Drawing Board** | Free drawing, colors, eraser, save artwork | 3-8 years |

## 🛠️ Tech Stack

```
HTML5 | CSS3 | Vanilla JavaScript
Web Speech API (Text-to-Speech)
HTML5 Canvas API (Drawing Board)
CSS Animations & Confetti Effects
GitHub Pages | Zero dependencies
```

---

## ✨ Key Features

- ✅ **Speech Synthesis** — Kids hear phonics sounds when they tap letters
- ✅ **Interactive Canvas** — Full drawing board with colors, brush sizes, eraser
- ✅ **Confetti Celebration** — Visual reward when kids interact
- ✅ **Mobile-First Design** — Touch-friendly for tablet and phone use
- ✅ **Offline-Friendly** — Works once loaded, no extra API calls
- ✅ **Free Forever** — No subscriptions, no ads
